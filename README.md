# Abhijeet Porwal — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website content and sections
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example, `abhijeet-portfolio`).
2. Upload all three website files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public website URL after deployment.
